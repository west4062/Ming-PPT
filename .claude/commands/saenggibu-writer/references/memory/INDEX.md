# 과목별 MEMORY 인덱스

생활기록부 평가문 작성에 대해 **사용자가 추가로 준 지시사항**을 과목별로 누적해 저장하는 곳입니다.
새 작업을 시작할 때(1단계) 해당 과목 파일을 먼저 읽어 기본 프롬프트 위에 사용자 취향을 반영합니다.

## 운영 규칙
- 과목 1개당 파일 2종: `<과목>.md`(누적 지시)와 `<과목>.prompt.txt`(맞춤 프롬프트). 파일명은 과목명 그대로(공백 제거). 예: `정보.md` + `정보.prompt.txt`.
- **맞춤 프롬프트**: 사용자가 별도 프롬프트 txt를 주지 않으면, 2단계에서 `assets/default_prompt.txt`를 그 과목의 기초 정보(사용 자료·과목명·분량 기준)에 맞게 적응해 `<과목>.prompt.txt`로 저장합니다. 같은 과목을 다시 작업하면 이 파일을 우선 사용하고, 자료·기준이 바뀌면 갱신합니다.
- 사용자가 "앞으로 ~하게 써줘", "이 과목은 ~를 강조해줘" 같은 **재사용할 지시**를 주면 `<과목>.md`에 한 줄로 추가하고, 프롬프트에 반영될 성격이면 `<과목>.prompt.txt`도 함께 고칩니다. 무엇을 저장·수정했는지 사용자에게 알립니다.
- 일회성 요청(이번 학생만 길게 등)은 저장하지 않습니다.
- 지시가 기존 항목과 충돌하면 덮어쓰고, 무엇을 바꿨는지 알립니다.
- 새 과목이면 파일을 만들고 아래 인덱스에 한 줄 추가합니다.
