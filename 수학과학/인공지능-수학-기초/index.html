왜 AI에 수학이 필요한가?

🔢 AI와 수학의 관계

모든 AI 알고리즘의 뿌리는 수학입니다

AI는 본질적으로 수학적 최적화 문제입니다. 데이터를 숫자로 표현하고(선형대수), 패턴의 가능성을 계산하며(확률통계), 오차를 줄이는 방향을 찾는 것(미적분) — 이 세 수학이 AI를 움직입니다.
📊

데이터 → 숫자

이미지, 텍스트, 소리 등 모든 데이터는 숫자(벡터·행렬)로 변환되어야 컴퓨터가 처리할 수 있습니다.

⚙️

패턴 → 공식

수백만 개의 데이터에서 규칙을 찾아 수학 함수로 표현하는 것이 머신러닝의 핵심입니다.

선형대수학 — 벡터와 행렬

📐 선형대수학 기초

AI가 데이터를 저장하고 변환하는 언어

벡터 (Vector)

크기와 방향을 가진 숫자 목록. 이미지 픽셀, 단어 하나를 숫자 배열로 표현합니다. 예: [0.2, 0.8, 0.5]

행렬 (Matrix)

벡터를 모은 2차원 배열. 신경망의 가중치(weight)를 행렬로 저장하고 연산합니다.

내적 (Dot Product)

두 벡터의 유사도를 측정합니다. 코사인 유사도·추천 알고리즘의 수학적 기반입니다.

선형변환

행렬 곱셈으로 데이터를 회전·확대·압축합니다. 딥러닝의 각 레이어가 이 변환을 수행합니다.

확률과 통계

🎲 확률과 통계

불확실한 세상을 수학으로 측정하는 도구

확률분포

특정 값이 나올 가능성을 수학적으로 표현합니다. 정규분포·이항분포가 AI 모델링에 활용됩니다.

기댓값과 분산

데이터의 평균(기댓값)과 퍼짐 정도(분산)를 계산합니다. 모델 성능 평가의 기준이 됩니다.

베이즈 정리

새 증거가 생길 때마다 확률을 업데이트합니다. 스팸 필터·의료 진단 AI의 핵심 원리입니다.

최대우도추정 (MLE)

관측 데이터를 가장 잘 설명하는 파라미터를 찾습니다. 모델 학습의 수학적 목표입니다.

미적분학 — 변화율과 최적화

📉 미적분학 기초

AI가 스스로 '학습'할 수 있는 수학적 이유

미분 — 변화율 측정

  • 도함수 f'(x): 함수의 순간 변화율
  • 편미분: 여러 변수 중 하나의 변화율만 측정
  • 연쇄 법칙: 복합 함수의 미분을 분해해 계산
  • 딥러닝 역전파(Backprop)가 편미분으로 구현됨

적분 — 누적과 면적

  • 정적분: 함수 아래 면적, 확률 계산에 활용
  • 손실 합산: 전체 데이터 오차의 합계
  • 기댓값 계산: 연속 확률변수의 평균값
  • 확률밀도함수의 정규화 조건 검증
핵심: 미분으로 어느 방향으로 움직여야 오차가 줄어드는지 알 수 있습니다 → 이것이 경사하강법의 원리입니다
경사하강법 — AI의 학습 원리

⚡ 경사하강법 (Gradient Descent)

AI가 스스로 오차를 줄여 나가는 알고리즘

①

손실함수 정의 (Loss Function)

모델 예측값과 실제값의 차이를 수치로 표현합니다. 이 값을 최소로 만드는 것이 학습의 목표입니다. 예: MSE = Σ(예측 − 실제)² / n

②

기울기 계산 (Gradient)

손실함수를 각 파라미터로 편미분하여 기울기를 구합니다. 기울기가 양수면 파라미터를 줄이고, 음수면 늘려 손실을 낮춥니다.

③

파라미터 업데이트 (Update)

θ ← θ − α · ∇L(θ) 공식으로 파라미터를 반복 업데이트합니다. α(학습률)는 한 번에 얼마나 이동할지 조절하는 하이퍼파라미터입니다.
